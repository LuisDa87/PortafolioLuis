# Personal Portfolio — Luis David Ducuara

A responsive personal portfolio created to present my early software development, robotics, and technology projects.

## About this project

This repository contains an early version of my portfolio website. It demonstrates responsive layout design, semantic HTML, reusable CSS styles, and lightweight JavaScript interactions.

## Features

- Responsive layout for desktop, tablet, and mobile.
- Sections for profile, skills, experience, education, projects, and contact information.
- Project cards built with CSS Grid.
- Flexible navigation and page layouts using Flexbox.
- Automatic image carousel.
- Subtle transitions and entrance animations.

## Technology stack

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Responsive media queries

## Run locally

No build step is required.

```bash
git clone https://github.com/LuisDa87/PortafolioLuis.git
cd PortafolioLuis
```

Open `index.html` in a browser.

## Project structure

```text
index.html    Main website structure and interactions
styles.css   Responsive styles, layout, and animations
images/      Portfolio images and project assets
README.md    Project documentation
```
